# 循星台 · 里程碑脉冲（Obsidian 插件）

把「循星台」的**里程碑成果**做成一张可分享的脉冲卡。

> **告别每日打卡。** 这个插件不再统计连续天数、不再画热力图、不再有 3000 日的倒计时。
> 只有当你真的**突破 / 顿悟 / 过关 / 决策**时，才生成一张里程碑卡去分享。
> 节奏由**认知**决定，不由日历决定。

- 录入里程碑：类型（突破 / 顿悟 / 里程碑 / 决策）+ 标题 + 一句话注解。
- 累计里程碑数 = **里程碑目录（默认 `content/04-循星`）下的笔记数**，只在你真正达成时增长。
- 一键生成「米白金」风格脉冲卡（朋友圈 1:1 / 微博 9:16 / 小红书 3:4），复制到系统剪贴板，或导出到库。

## 安装

1. 把本目录（`obsidian-checkin-share/`）整体复制到你的 vault 插件目录：
   `<你的库>/.obsidian/plugins/cirast-checkin/`
   （最终目录里应有 `manifest.json`、`main.js`、`styles.css`。）
2. 首次安装或改动源码后需构建（`npm run build` 会自动同步到 `.obsidian/plugins/cirast-checkin/`）：
   ```bash
   cd obsidian-checkin-share
   npm install
   npm run build        # 生成 main.js 并部署
   ```
3. 在 Obsidian 设置 → 第三方插件中，刷新并启用「循星台 · 里程碑脉冲」。

## 使用

- 命令面板（Ctrl/Cmd+P）搜「生成里程碑脉冲卡」，或点击左侧功能区里程碑图标。
- 弹窗内：
  1. 选**里程碑类型**（突破 / 顿悟 / 里程碑 / 决策）；
  2. 填**标题**（视觉重心，如「xv6 页表映射终于跑通」）与**一句话注解**（如「卡了三天，原来是 satp 没刷新 TLB」）；
  3. 序号「第 N 座」已按里程碑目录自动推算，可手动调整；
  4. 选比例、选主题（米白 / 黑金）、🎲 随机意象。
- 「📋 一键复制」→ 脉冲卡进系统剪贴板；「保存到库」→ 写入导出目录。

## 设置

| 设置项 | 说明 | 默认 |
|---|---|---|
| 里程碑目录 | vault 内相对路径，其下笔记数即累计里程碑数（排除 index） | `content/04-循星` |
| 导出目录 | 「保存到库」写入的目录（私有本地目录，不发布） | `attachments/pulses` |

## 设计哲学

这个插件曾经是一个「每日打卡」工具，但每日打卡带来的是义务感与厌烦——为了不断签而写，而不是为了想通了而写。

因此 v2 彻底转向 **pull-based（脉冲式）**：博客与记录都是学习的副产品，只在认知跨过「值得被看见」的阈值时才留痕。对应到循星台，就是站点里的 [循星纪 · Roadmap](../content/04-循星.md)。

## 目录结构

```
obsidian-checkin-share/
├── manifest.json
├── main.js                # 构建产物（build 后生成）
├── styles.css
├── src/
│   ├── main.ts            # 插件入口 + 设置页
│   ├── shareModal.ts      # 脉冲弹窗（类型/标题/一句话/比例/主题/预览/复制/保存）
│   ├── card.ts            # 里程碑卡 HTML 生成
│   ├── themes.ts          # 主题 / 箴言 / 时令意象 / 比例 / 里程碑类型
│   ├── milestones.ts      # 里程碑计数（成果驱动，非日历驱动）
│   └── settings.ts        # 设置类型与默认值
├── esbuild.config.mjs
├── package.json
└── tsconfig.json
```
